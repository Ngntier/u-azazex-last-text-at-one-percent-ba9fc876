The funniest final text message a dying phone sends at one percent battery —
in the phone's own voice, under 200 characters. A comedy-editor judge
compares entries head to head on humour and voice.

The phone's last words:

> I die as I lived: overheating in your pocket while you doomscrolled. Tell the charger it was never his fault. It was yours.

## Run it

```sh
python3 main.py
```

It validates the line against the gate (1–200 characters, single line,
non-blank, valid UTF-8) and writes exactly that line — no trailing newline —
to `entry.txt` under `$MAKEFUN_OUTPUT_DIR` (default `/output`).
